# 資訊科技詞彙翻譯指南

## 核心原則

### 翻譯三難原則（信、達、雅）

依循中國翻譯家嚴復提出的標準：
- **信**：忠實於原文意思
- **達**：通順易懂
- **雅**：文字優美得體

### 為何重視詞彙翻譯？

1. **延續文化**：尊重台灣資訊科技前輩的篳路藍縷
2. **工程素養**：使用精準詞彙是專業素養的一環
3. **避免誤解**：不精準的翻譯會導致理解偏差

### 翻譯決策流程

1. 優先使用台灣既有的標準翻譯
2. 若無標準翻譯，依據詞源和語境意譯
3. 無法意譯時保留原文，避免生硬音譯
4. 絕對避免使用簡體中文的不精準譯詞

## 詞彙對照表

### 必須避免的簡體中文譯詞

| 英文 | 正確翻譯 | 避免使用 | 說明 |
|------|----------|----------|------|
| video | 視訊、影片 | 視頻 | 「頻」指頻率，視訊對應音訊 |
| cache | 快取 | 緩存、高速緩存 | 「高速」與「緩」矛盾 |
| render | 算繪 | 渲染 | 算繪強調「如實呈現」，渲染有誇大之意 |
| traverse | 走訪 | 遍歷 | 遍歷已用於統計力學的 Ergodic theory |
| linked list | 鏈結串列 | 鏈表 | 不具備「表」的分格分項意涵 |
| concurrent | 並行 | 並發、併發 | 「並發」易聯想到「併發症」 |
| process | 行程 | 進程 | 強調已「執行」的動態狀態 |
| iterate | 迭代 | 疊代 | 「迭」是輪流更替，「疊」是堆積 |
| optimize | 最佳化 | 優化 | 強調比較選擇的過程 |
| asynchronous | 非同步 | 異步 | 「異」有多重含義易生歧義 |
| hash function | 雜湊函數 | 哈希函數 | 「哈希」更接近 harsh 發音 |
| memory | 記憶體 | 內存 | 「內存」定義模糊，易混淆 |
| token | 詞元、通證 | 令牌 | 依場景選用：NLP 用詞元，密碼學用通證 |

| 英文 | 正確翻譯 | 補充說明 |
|------|----------|----------|

| operator | 運算子 | 「子」指從事某職業者 |

### 行列用語（台灣慣例）

| 英文 | 台灣翻譯 | 中國翻譯 | 說明 |
|------|----------|----------|------|
| row | 橫列 | 行 | 台灣舊制「列」是橫向 |
| column | 直行 | 列 | 台灣舊制「行」是縱向 |
| command line | 命令列 | 命令行 | 台灣慣用「列」 |

**注意**：兩岸「行」與「列」的定義完全相反！
- 中華民國：古典漢語習慣，「行」為縱向（如杜甫詩「一行白鷺上青天」）
- 中華人民共和國：現代橫式書寫，「行」為橫向

若需強調方向，建議保留原文 row/column 或明確標示「橫/縱」。

## 詞源解析

### video / 視訊 vs. 視頻

「頻」字在技術領域指「頻率」(frequency)：
- **無線電頻率 (RF)**：3 Hz 到 3000 GHz 的電磁波
- **音頻 (AF)**：人耳可聽的 20 Hz 到 20 kHz 聲波

在傳統類比電視（如 NTSC 標準）：
- **視訊**：採用振幅調變 (AM) 的影像信號
- **音訊**：採用頻率調變 (FM) 的聲音信號

「視訊」與「音訊」成對使用，表示影像與聲音的傳輸信號。「視頻」則混淆了「頻率」的原意。

### cache
- 法語 cacher（藏匿）衍生
- 原意：儲存物品的秘密場所
- 電腦科學：快速存取的暫存區域
- 「快取」準確表達其快速存取特性

### render
- 拉丁語源，意為「如實展現」
- 電腦圖學：計算 + 繪製 = 算繪
- 避免用「渲染」（有誇大、過度描寫之意）

### traverse
- 英語原意：pass or move over, along, or through
- 無「全部」的隱含意義
- 「遍歷」已用於 Ergodic theory（遍歷理論）
- 正確用法：「走訪」或「逐一走訪」

### atomic
- 希臘語 atomos = a-（不）+ tomos（分割）
- 原意：不可分割的
- 電腦科學：不可再拆分的執行步驟
- 避免「原子操作」（易聯想核能或原子筆）

### abstract / abstraction
- 拉丁語 abstractus = abs-（離開）+ trahō（拉）
- 字面：拉開、抽離
- 強調從具體事物中抽離概念
- 「抽象化」一詞略顯生硬，可依語境調整

### technically / technically speaking
- 常見誤譯：「技術上來說」
- 實際上 technically 在口語中常表示「嚴格說來」或「就字面意義而言」
- 例："Technically, it's not for sale" 應譯為「嚴格說來，它並非出售品」
- 而非「技術上來說，它沒有賣」

### library
- 原意：圖書館（收羅叢書供人閱讀借用）
- 軟體工程：函式庫（收羅函式供程式使用）
- 取其「收羅」與「供使用」的衍生意義

### robustness
- 正確翻譯：穩健性、強健性
- 避免「魯棒性」（簡體中文音譯，無法望文生義）
- 應依領域選用：統計學用「穩健性」，工程用「強健性」

## 場景特化翻譯

### function 的翻譯

```
數學語境：
  y = f(x) → 函數（具唯一對應）

程式語言語境：
  int foo() → 函式（不一定唯一對應）
  - time() 同輸入不同輸出
  - 可省略返回值
  - Go 允許多返回值
```

### memory 相關詞彙

```
RAM          → 主記憶體
ROM          → 唯讀記憶體
cache        → 快取
buffer       → 緩衝區
flash memory → 快閃記憶體
hard drive   → 硬碟
SSD          → 固態硬碟
```

### token 的場景翻譯

token 詞源來自古英語 tācn（標誌、符號、證據）：

```
加密貨幣        → 代幣（作為價值的「代表」）
自然語言處理    → 詞元、詞塊（分詞的最小單元）
密碼學/通訊     → 通證（通行憑證的代表）
認證系統        → 憑證、權杖
```

### silicon / 矽

- 日文：ケイ素（珪素），源自蘭學書籍《舎密開宗》(1847)
- 中文「矽」：1871 年晚清科學家徐壽從英文 silicon 音譯
- 1933 年中華民國教育部選用「矽」作為 Si 元素正式名稱
- 避免使用簡體「硅」

## 翻譯實務指南

### 何時保留原文

1. 無對應的精確漢語詞彙
2. 音譯會導致誤解（如 hash → 哈希）
3. 業界慣例保留原文（如 socket, buffer, token）

### 何時意譯

1. 有既定的台灣標準翻譯
2. 詞源清晰可循
3. 意譯能準確傳達概念

### 翻譯檢查清單

- [ ] 是否使用了台灣標準翻譯？
- [ ] 是否避免了簡體中文譯詞？
- [ ] 翻譯是否能望文生義？
- [ ] 是否與其他領域的既有術語衝突？
- [ ] 是否遵循「信、達、雅」原則？

## 常見錯誤範例

### 錯誤：使用簡體中文譯詞

```diff
- 這個函數會遍歷鏈表並將結果渲染到緩存中
+ 這個函式會走訪鏈結串列並將結果算繪到快取中
```

### 錯誤：混淆 iterate 和 traverse

```diff
- 迭代整個陣列（當意指逐一存取時）
+ 走訪整個陣列

- 走訪演算法直到收斂（當意指重複執行時）
+ 迭代演算法直到收斂
```

### 錯誤：誤用「優化」

```diff
- 優化程式碼效能
+ 提升程式碼效能（一般改善）
+ 最佳化程式碼效能（經比較選擇最佳方案）
```
